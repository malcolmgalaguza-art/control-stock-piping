# Control de Stock Piping — Streamlit

## Ejecutar localmente
1. Instalar Python.
2. Abrir una terminal en esta carpeta.
3. Ejecutar `pip install -r requirements.txt`
4. Ejecutar `streamlit run app.py`

## Publicar como aplicación web
Se puede desplegar desde un repositorio GitHub en Streamlit Community Cloud.
Esta versión carga los Excel manualmente desde la interfaz; no conecta automáticamente a Drive.
Antes de usar datos reales de la empresa, confirmar que el alojamiento esté autorizado por SACDE.
